**`def search_places(query: str, city: str, max_results: int, api_key: str) -> list[dict]`**

- Endpoint: `POST https://places.googleapis.com/v1/places:searchText`
- Headers:
  ```python
  headers = {

  }
  ```
- Request body: `{"textQuery": f"{query} em {city}", "languageCode": "pt-BR"}`
- Returns: list of raw place dicts (from `response.json().get("places", [])`)
- Only requests DISC-06-compliant fields — no `places.photos`, `places.reviews`, `places.priceLevel` or other Pro SKU fields.
- Single-page fetch only (pagination is added in Plan 02).

**`def extract_lead(place: dict, segment: str, city: str) -> dict`**

Extracts and maps fields from a raw place dict to the leads schema:
```python
def extract_lead(place: dict, segment: str, city: str) -> dict:
    name = place.get("displayName", {}).get("text", "").strip()
    address = place.get("formattedAddress", "").strip()
    phone = place.get("internationalPhoneNumber", "").strip() or None
    site = place.get("websiteUri", "").strip() or None
    has_site = site is not None
    return {
        "name": name,
        "segment": segment,
        "city": city,
        "address": address or None,
        "phone": phone,
        "site": site,
        "has_site": has_site,
    }
```

In `main()`, call `search_places()` and print extracted leads to stdout (temporary verification output):
```python
places = search_places(args.query, city, args.max_results, GOOGLE_MAPS_API_KEY)
leads = [extract_lead(p, segment, city) for p in places[:args.max_results]]
for lead in leads:
    print(lead)
```
