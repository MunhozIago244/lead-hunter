# Phase 13 Plan 01

## Objective

Create the backend automation path that ingests official WhatsApp events and updates CRM reply state automatically once a connection exists.

## Deliverables

- `POST /api/crm/whatsapp/sync`
- optional dedicated `CRM_WHATSAPP_INGESTION_SECRET`
- batch message processing into `crm_messages`
- automatic outreach-event creation for sent WhatsApp messages and detected replies
- derived CRM account updates for outbound and inbound WhatsApp activity
