# Phase 12 Plan 01

## Objective

Create the backend automation path that ingests email events and updates CRM reply state automatically once a provider connection exists.

## Deliverables

- `POST /api/crm/email/sync`
- ingestion secret requirement for the email automation route
- batch message processing into `crm_messages`
- automatic outreach-event creation for sent emails and detected replies
- derived CRM account updates for outbound and inbound email activity
