# Phase 09 Plan 01

## Objective

Create the CRM foundation schema so the system can evolve from lead management into account, outreach, and reply lifecycle management.

## Deliverables

- `crm_accounts` linked one-to-one to an optional source `lead`
- `crm_contacts` for primary and secondary contact points
- `crm_deals` for commercial opportunities
- `crm_outreach_events` for proposal and follow-up activity
- `crm_messages` for normalized inbound/outbound history
- `crm_channel_connections` for email/WhatsApp integration metadata
- `crm_sync_jobs` for automation and sync observability
- Shared TypeScript types aligned with the new tables and enums

## Notes

- This phase intentionally stops before route creation or dashboard UI work
- Email/WhatsApp automation will land in later CRM phases after manual connection setup exists
