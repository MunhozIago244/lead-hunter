</objective>

- `score_mobile = 0`
- `score_speed = 0`
- `score_seo = 0`
- `score_design = 0`

  <files>scraper/scraper.py</files>
  <action>
Implement `analyze_pagespeed(site_url: str, api_key: str) -> dict` that:

- calls PageSpeed Insights v5 with `strategy=mobile`
- parses `lighthouseResult.categories.performance.score`
- parses `lighthouseResult.categories.seo.score`
- maps the normalized 0-1 values to 0-100 integers
- returns null-safe fields if the request times out or the site is unreachable

Wire this into the scraper before persistence for leads that have a site.
